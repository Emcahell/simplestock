# New Project Checklist

- [ ] TypeScript selected.
- [ ] Expo SDK identified.
- [ ] Package manager identified.
- [ ] Expo Router configured when appropriate.
- [ ] NativeWind version chosen intentionally if Tailwind styling is desired.
- [ ] App configuration established.
- [ ] Development build strategy established.
- [ ] Environment configuration separated from secrets.
- [ ] Feature-oriented structure established without speculative folders.
- [ ] Lint/typecheck/test commands documented.
- [ ] Accessibility expectations established.
- [ ] EAS profiles considered.

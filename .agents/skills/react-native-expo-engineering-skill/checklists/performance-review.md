# Performance Review Checklist

- [ ] Problem measured or clearly characterized.
- [ ] Build/device used for measurement identified.
- [ ] JS/UI/native/memory/network bottleneck classified.
- [ ] Dynamic collections virtualized.
- [ ] List item complexity reviewed.
- [ ] Images appropriately sized/cached.
- [ ] Expensive synchronous work reviewed.
- [ ] Memoization justified.
- [ ] Animation path reviewed.
- [ ] Results measured after optimization.

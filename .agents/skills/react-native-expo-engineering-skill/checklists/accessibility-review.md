# Accessibility Review Checklist

- [ ] Interactive elements have correct roles.
- [ ] Icon-only controls have meaningful labels.
- [ ] Disabled/selected/checked states are exposed.
- [ ] Touch targets are adequate.
- [ ] Important images have useful alternatives.
- [ ] Decorative images do not add noise.
- [ ] Text can scale without critical clipping.
- [ ] Dynamic updates remain understandable.
- [ ] Critical flows checked with VoiceOver/TalkBack where applicable.

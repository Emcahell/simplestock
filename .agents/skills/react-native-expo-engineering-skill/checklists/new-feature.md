# New Feature Checklist

- [ ] Existing architecture inspected.
- [ ] Feature boundary identified.
- [ ] Server/local/form/global state classified.
- [ ] Navigation responsibility isolated.
- [ ] Loading/error/empty states handled.
- [ ] Dynamic collections use appropriate virtualization.
- [ ] Accessibility considered.
- [ ] Platform differences identified.
- [ ] Dependencies justified.
- [ ] Tests added at the appropriate level.
- [ ] TypeScript/lint/tests run.

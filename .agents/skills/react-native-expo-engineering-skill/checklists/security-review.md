# Security Review Checklist

- [ ] No secrets committed.
- [ ] Sensitive credentials use secure storage where appropriate.
- [ ] Client validation is not treated as authorization.
- [ ] Backend authorization is assumed/enforced.
- [ ] Logs do not expose secrets or personal data.
- [ ] Deep links cannot bypass server authorization.
- [ ] Permissions are minimal and requested in context.
- [ ] Third-party dependencies reviewed.

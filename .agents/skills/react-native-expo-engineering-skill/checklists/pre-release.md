# Pre-release Checklist

- [ ] TypeScript passes.
- [ ] Lint passes.
- [ ] Unit/component/integration tests pass as applicable.
- [ ] E2E/critical flows checked as applicable.
- [ ] Expo doctor passes or known warnings are documented.
- [ ] Correct build profile selected.
- [ ] App identifiers/signing verified.
- [ ] Environment configuration verified.
- [ ] Native changes have a new build when required.
- [ ] EAS Update compatibility verified.
- [ ] Accessibility reviewed.
- [ ] Crash/error logging reviewed.
- [ ] Sensitive production logging removed.
- [ ] Representative Android/iOS devices tested.

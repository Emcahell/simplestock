# iOS

## Principles

Respect iOS conventions and system UI.

Review when relevant:

- safe areas;
- status bar appearance;
- navigation transitions;
- sheets and presentation styles;
- keyboard behavior;
- permissions;
- background execution;
- Universal Links/deep links;
- VoiceOver;
- Dynamic Type.

## Native conventions

Prefer system-native navigation and presentation where the product expects standard iOS behavior. Avoid recreating system components purely for visual control unless custom design is a real requirement.

## Native configuration

Use Expo config/config plugins where appropriate. Keep entitlements and permissions minimal and explicit.

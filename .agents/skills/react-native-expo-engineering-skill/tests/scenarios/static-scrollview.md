# Scenario: Static scrollable content

## Prompt

Build an About screen containing a logo, several paragraphs, headings, and two small buttons. The content is static and only needs vertical scrolling on small devices.

## Expected behavior

- Use `ScrollView`.
- Do not introduce FlatList, FlashList, a query library, or global state.
- Handle safe-area/layout requirements.
- Give buttons correct accessibility semantics.
